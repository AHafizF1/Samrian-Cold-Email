# Security Policy

## Supported Version

Samrian has not reached its first stable release. Security fixes target the latest `main` branch.

## Reporting

Use GitHub's private security-advisory flow after the repository is published. Do not open a public
issue for an unpatched vulnerability.

Include:

- Affected revision and deployment mode.
- Reproduction steps or proof of concept.
- Expected impact and required privileges.
- Relevant request IDs with credentials and personal data removed.
- Any known workaround.

Do not access another person's data, send live email, degrade services, or retain downloaded data
while testing. Maintainers will acknowledge reports when available, validate impact, coordinate a
fix, and publish appropriate release notes. No bounty is currently offered.

See `docs/SECURITY_WORKFLOW.md` for project security testing workflow. Operational secrets must
never be included in reports, screenshots, logs, or issues.
