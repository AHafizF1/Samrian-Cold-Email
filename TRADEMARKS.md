# Trademark Policy

This policy covers the Samrian name, logos, and other project branding. Software licenses grant
copyright permissions; they do not grant trademark rights or imply endorsement.

You may:

- Truthfully state that software is "based on Samrian."
- Link to the official Samrian project.
- Describe compatibility with Samrian.
- Use the name when discussing or contributing to the project.

Please do not:

- Present a fork, hosted service, or modified distribution as the official Samrian service.
- Use confusingly similar branding, logos, domains, or account names.
- Claim sponsorship, certification, partnership, or endorsement without written permission.
- Remove attribution in a way that misleads users about software origin.

Forks should use their own primary name and visual identity. A clear phrase such as "based on
Samrian" is welcome when it accurately describes the relationship.

Open a repository issue for permission questions or uses not covered here.
